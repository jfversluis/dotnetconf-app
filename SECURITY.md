# Security policy

## Supported versions

This project is in development. Security fixes are made on `main`; use the
latest available build and report the version or commit you tested. Older
development snapshots are not maintained separately.

iOS and Android are the primary targets. Linux desktop and browser builds are
experimental and do not yet have mobile feature or validation parity. Security
reports for any target are welcome.

## Report a vulnerability privately

**Do not disclose vulnerabilities, credentials, or exploit details in public
issues, pull requests, or discussions.**

Email [dotnetconfapp@geraldversluis.nl](mailto:dotnetconfapp@geraldversluis.nl)
with the subject `.NET Conf app security report`. This is the app's existing
support contact and does not require repository access or a GitHub account.

Include:

- The affected app version or commit, platform, and OS version.
- A description of the issue, its impact, and steps to reproduce it.
- A minimal proof of concept or redacted logs/screenshots, if useful.
- A way to contact you for follow-up and your preferred disclosure credit.

Do not send live credentials, personal data, or another person's app data.
Email is not an end-to-end encrypted reporting channel; if sensitive evidence
is necessary, describe it first and arrange a suitable transfer with the
maintainer. Test only on your own devices and data or with explicit permission.

The maintainer will review reports and coordinate remediation and disclosure
with the reporter. This volunteer project does not guarantee response or fix
times. If you have not received a reply, follow up on the same email thread
rather than posting vulnerability details publicly.

GitHub's **Report a vulnerability** option can also be used if it is available
under this repository's Security tab. If it is absent, use email. GitHub's
private vulnerability reporting feature is only available for public
repositories and must be enabled separately; this policy does not imply it is
enabled.

## Other reports

Use ordinary GitHub issues for non-sensitive bugs and feature requests. See the
[contributor guide](CONTRIBUTING.md) for development and verification guidance.
